# CBB Picks

College basketball spread and over/under picks from a machine-learning model, updated automatically through the day.

- **Picks:** https://assistjmd.github.io/cbb-picks/
- **How it works:** https://assistjmd.github.io/cbb-picks/methodology.html

## In brief

- **The model:** gradient-boosted tree models project every Division I game's margin and total from opponent-adjusted efficiency ratings, box-score "four factors", pace, matchup and situational data, as known the day before each game. The model never sees the betting line.
- **Testing:** walk-forward out of sample from 2018 to 2026. Each season is predicted by a model trained only on earlier seasons, and picks are graded against opening, evening and closing lines.
- **Rules:** totals need a 3+ point gap from the line (5+ in the season's first two weeks). Spreads need 4+ and run only in November–December. There are no moneyline picks.
- **Timing matters:** the edge is in early lines, so picks post the evening before. By tip-off the market has mostly caught up.
- **Referee crews:** a pick is tagged when the officials assigned to the game have historically leaned the same way.
- **Testing discipline:** 278 popular situational angles were pre-registered and tested on held-out seasons. None earned a place in the rules.

For fun, not financial advice. Bet only what you can afford to lose.
