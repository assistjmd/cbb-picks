How to read this

The pick is the side and the line it was made at. If your book has a worse number, the edge is smaller.

Model is the model's own projected margin or total; edge is how far that is from the line, in points. Totals need 3+ points of edge (5+ in the season's first two weeks); spreads need 4+ and only run in November–December.

2× ref crew: the officials posted before tip and historically lean the same way, so the model would bet it again.

Late: the line first showed up on game day, after the best value is usually gone.

Units assume 1 unit risked per pick at −110.

For fun. A model, not a guarantee. Bet only what you can afford to lose.
